# HUNEW releases

Veřejné instalátory HUNEW (bez zdrojového kódu).

- **Aktuální verze:** viz [manifest.json](manifest.json) nebo [Releases](https://github.com/gummidek/hunew-releases/releases/latest)
- **Zdroják:** privátní repo [gummidek/Hune](https://github.com/gummidek/Hune)

HUNEW kontroluje updaty přes `manifest.json` v `main` větvi.
